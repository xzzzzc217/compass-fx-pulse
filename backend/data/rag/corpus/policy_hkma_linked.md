# 金管局保卫港币联系汇率的强弱方兑换保证

## 1. 定义与背景

联系汇率制度是香港自1983年起实施的货币制度，核心是将港币与美元挂钩，汇率固定于 **1美元兑7.80港币**。香港金融管理局（金管局，HKMA）通过“强弱方兑换保证”机制，确保汇率在 **7.75至7.85** 的窄幅区间内波动。当港币汇率触及区间边界时，金管局会主动介入，以维持货币稳定。

该机制本质是“货币发行局”制度（Currency Board System）的延伸，要求港币的发行必须有等值美元储备支持。强弱方兑换保证是金管局对市场承诺的“最后防线”，旨在防止汇率大幅偏离挂钩水平，从而维护香港作为国际金融中心的信心。

## 2. 强方兑换保证机制

当港币需求强劲、汇率升至 **1美元兑7.75港币**（即强方兑换保证触发点）时，金管局会向银行卖出港币、买入美元。这一操作增加港币供应，使汇率回软至7.75以内。

**机制示意**：
- 假设市场情绪推高港币至7.74，触发强方保证。
- 金管局按7.75的固定价向银行出售港币，回收美元。
- 银行套利：用1美元从金管局换得7.75港币，再在市场上以7.74卖出港币，赚取0.01港币/美元的差价（扣除交易成本后仍有利润）。
- 套利行为增加港币供给，汇率回落至7.75以下。

**历史案例**：2020年全球低利率环境下，资金涌入香港，港币多次触及7.75强方兑换保证。金管局频繁出手，累计买入超3000亿港元等值美元，但始终守住7.75底线。

## 3. 弱方兑换保证机制

当港币遭抛售、汇率跌至 **1美元兑7.85港币**（弱方兑换保证触发点）时，金管局会买入港币、卖出美元，减少港币供应，支撑汇率。

**数值演示**（假设利差驱动）：
- 假设美国利率为5%，香港利率为3%，利差2%导致套利者卖出港币、买入美元以获取更高收益。
- 港币跌至7.85，触发弱方保证。
- 金管局按7.85从银行买入港币，卖出美元。例如，银行用1亿港币换得约1273.9万美元（1亿÷7.85）。
- 银行随后在市场上以7.86卖出美元、买入港币，套利0.01港币/美元。
- 套利活动减少港币供给，汇率回升至7.85以上。

## 4. 影响因素与风险

**核心驱动因素**：
- **利差**：港美利差扩大（如美联储加息快于香港）会触发套利，导致港币走弱，考验弱方保证。
- **资本流动**：地缘风险或市场恐慌可能引发资金外逃，冲击弱方保证；反之，避险资金涌入则考验强方保证。
- **金管局储备**：香港外汇储备规模（通常超过4000亿美元）是信心基石，足以应对大规模干预。

**风险点**：
- 若持续干预导致港币基础货币收缩，可能推高本地利率，影响经济。
- 极端情况下（如1997年亚洲金融危机），投机者可能同时攻击股市和汇市，但金管局通过“利率调节”和“流动性管理”应对，例如提高银行间利率以增加做空成本。

## 5. 总结

强弱方兑换保证是联系汇率制度的“自动稳定器”，通过金管局在7.75-7.85区间的双向承诺，将汇率波动锁定在极小范围。该机制依赖市场套利行为自动恢复平衡，而金管局仅作为最后做市商介入。对于投资者而言，理解这一机制有助于评估港币的稳定性——只要香港外汇储备充足且制度可信，港币汇率便不会脱钩。
